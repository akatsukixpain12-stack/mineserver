# Pumpkin source integration

Mineserver is integrating the upstream Pumpkin Minecraft server as a vendored source tree, adapted for a web-based control plane.

Upstream project: Pumpkin-MC/Pumpkin
Upstream commit: a8db585158ba109b4664eb755d7be76f20ac8f6b
License: GPL-3.0

Required upstream copyright and license notices must remain with the vendored source. Mineserver branding only applies to Mineserver's own web/control-plane layer and to permitted user-facing adaptations; it does not remove or replace upstream attribution.

The repository is intentionally not using a Git submodule for the server source.
